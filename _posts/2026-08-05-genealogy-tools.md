Some genealogy tools I have found interesting. 

List will be expanded as time goes by.


* Sofware 

I will only consider Free Libre Open Souce Sofware. 

** Gramps 

Nice name and the reference FLOSS genealogy Sofware.

My small annoyances with it are :
 - lack of real synchronization with websites, but I'll might find a plugin for that. 
 - not great keyboard for only work and I feel I lose a lot of time closing windows.

 ** Ancestris 

Need to see if this could be a good contender.

* Web sites 

** Geni 

Nice free features. The paid version is too expensive. 

** Geneanet 

Not too expensive monthly fee, but not a lot of features if you don't have a free account. 
I will see if this can be used for my family to collaborate online. 
Only one tree per account. 
Only import data to people already in your tree (or related to someone that is).

* Tools 

** GEDminer - In-Browser GEDCOM Analysis Tool

Upload and analyse your GEDCOM file in your browser.
Spot errors, duplicates and gaps, and explore migration patterns - free, no signup. Data stays in-browser and isn't sent to servers.

This gives a nice visualation of GEDCOM data, but I would have believde it to be more about GEDCOM format.
