Posts formats is `_posts/YYYY-MM-DD-title.md`. 
Jekyll will then proceed by processing them into static html files. 

I've connected the URL `samusz.muszlak.com` to the github page's url by adding a CNAME record in my registar's record and adding it in the `Custom Domain` section in GitHub page. 

For now, the `Settings` > `Pages` I've checked on the `Enforce HTTS` in the `Custom Domain` section. 
I'll wait to see if the https will work once this record is propagated in the DNS servers.
